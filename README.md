# 💊 MediAlert – Smart Medicine Reminder Web Application

MediAlert is a full-stack web application designed to help users manage their medication schedules effectively. It enables users to add medicines, set reminder timings, receive notifications, and track their medication history, ensuring they never miss an important dose.

---

## 🚀 Features

- 👤 User Authentication (Register/Login)
- 💊 Add, Edit, and Delete Medicines
- ⏰ Smart Medicine Reminders
- 🔔 Notification Alerts
- 📅 Daily Medication Schedule
- ✅ Mark Medicines as Taken
- 📊 Medication History Tracking
- 📱 Responsive User Interface
- 🔒 Secure User Data Storage

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/ISHI-456/MediAlert--Smart-Medicine-Reminder-Web-Application.git
```

### Navigate to Project

```bash
cd MediAlert--Smart-Medicine-Reminder-Web-Application
```

### Install Dependencies

#### Frontend

```bash
cd client
npm install
```

#### Backend

```bash
cd ../server
npm install
```

---

## ▶️ Run the Project

### Start Backend

```bash
npm start
```

or

```bash
npm run dev
```

### Start Frontend

```bash
cd client
npm start
```

The application will run locally on:

```
Frontend: http://localhost:3000
Backend: http://localhost:5000
```
